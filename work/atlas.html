Why this shape

API can be rewritten without touching idempotency. Indexer catch-up is RPC-bound; portfolio is query-bound. Mixing them is how p95 dies. Redis down: fail closed on rate limit, serve portfolio from Postgres. Kafka down: HTTP still commits the outbox.
